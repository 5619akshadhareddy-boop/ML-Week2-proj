# Part of my internship - Week 2

This project builds supervised machine learning models for house price and Titanic survival prediction using Python.

🚀 **Overview**

* **Goal:** Train Linear Regression and Logistic Regression models, evaluate performance, and visualize predictions.
* **Tools:** Python, Pandas, Scikit-Learn, Matplotlib, Seaborn.

📋 **Steps Performed**

1. **Data Preprocessing:** Handled missing values, encoded categorical features, and split datasets (80% training, 20% testing).
2. **Model Training:** Built a Linear Regression model for the housing dataset and a Logistic Regression model for the Titanic dataset.
3. **Evaluation:** Evaluated models using $R^2$ score, RMSE, accuracy score, and classification reports.
4. **Visualization:** Generated actual vs. predicted price plots and confusion matrix heatmaps.

📁 **Repository Files**

* `House_Price_Prediction.py` - Main Python script for housing regression
* `Titanic_Survival_Prediction.py` - Main Python script for Titanic classification
* `archive.zip` / `Housing.csv` - Housing dataset
* `Titanic-Dataset.csv` - Raw Titanic dataset
